# Fx InvoiceGenrator

An Invoice Generator.

![Fx InvoiceGenerator](screenshot2.png)

## About

This is an invoice generator with a clean minimal look, and a working print as well as download as a pdf button. 

**[Demo ](https://president-john-os.vercel.app/)**

## Features 

*  Pdf Download
*  Direct Print Support
*  Light/Dark Mode

## Planned Upcoming Features

* Log in page
* Invoice History
* Direct Email
* Logo

## Built using

* **HTML5** 
* **CSS3** 
* **JavaScript** 
* **Vercel** 
* **jsPDF**
* **html2canvas**
